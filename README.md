# Hands-on Project: Generative AI for Model Development

In this hands-on project, we explore how generative AI can help create Python scripts for developing and evaluating different predictive models using a given dataset.

**Source:** [Coursera](https://www.coursera.org/learn/generative-ai-elevate-your-data-science-career/ungradedLti/DpfcC/hands-on-lab-generative-ai-for-models-development)

## Objectives

In this project, we will use generative AI to generate Python code and work with different regression techniques. The main objectives are to:

- Apply **simple linear regression** to fit a model using a single independent variable.
- Apply **multiple linear regression** to fit a model using multiple independent variables.
- Use **polynomial regression** to model nonlinear relationships between variables.
- Build a **machine learning pipeline** that combines polynomial feature transformation with linear regression.
- Use **grid search with cross-validation** and **ridge regression** to identify the optimal model hyperparameters.
